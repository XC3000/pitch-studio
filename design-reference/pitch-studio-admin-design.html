This is a static design mockup — nothing here is wired up to a backend, but the Presentations screen is interactive. The model: each presentation holds the deck plus a default language and default presenter; each presentation then has many share links, one per recipient, each with its own unique code (/p/meridian-en-4f7q?to=David) so views are tracked per person. A link inherits the presentation defaults and can override language, presenter, and recipient — click Share links on any row, then Edit a link, change its language and watch the URL and override chips update; Revoke/Re-enable, add new links, or change the defaults and see default-following links switch instantly. The other screens are unchanged: Scene Builder (intent → generated script & visual, with AI-model cost picker), Template Queue (approve generated visuals into the library), and the Knowledge base powering cited live Q&A.
