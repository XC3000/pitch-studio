## 1. What we're building

**Pitch Studio** — a multi-tenant SaaS that turns a company's sales pitch into an interactive, avatar-led web presentation. A pre-generated HeyGen avatar video presents scene-by-scene with animated metrics, evidence documents, and interruptible RAG-grounded Q&A.

- **Tenant #1:** CredibleAssist — a medical-assistance company pitching insurance companies. Multi-tenant from day one; CredibleAssist is just the first org.
- **Two surfaces:**
  - **Admin studio** (auth'd): Presentations, Scene Builder, Template Queue, Knowledge/RAG, Analytics. Routes under `/o/{orgSlug}/…`.
  - **Public viewer** (no auth): share links `/p/{presentationSlug}-{lang}[-{code}]`. The avatar presents; prospects can interrupt with questions.

### Binding decisions (do NOT relitigate)
- **English only** at first send; Arabic/RTL is a later milestone (M7).
- **Pre-generated avatar videos only** — no real-time avatars, ever, in v1.
- **Real RAG with citations + editable fallback** from M3 (no free-generation without grounding).
- **Tiered retrieval** (added to M3 scope 2026-07-07): a question searches progressively wider pools and stops at the first that clears the grounding threshold — (1) documents attached to the **current scene**, (2) documents scoped to the **current presentation**, (3) **org-wide** documents (shared across all presentations) — else the org fallback. Documents are **opt-in to RAG at upload time** (a doc can be "stored only" — shown in the evidence panel, never chunked/embedded/searchable). Scene-level attach/detach of already-uploaded documents is a **Scene Builder (M4)** UI; the schema (`scenes.documentIds`) already supports it, so M3 only needs to build the presentation-scope picker in the Knowledge console.
- **Q&A answers** = streamed captions + ElevenLabs TTS in the presenter's voice.
- **No billing integration now** — meter usage into `UsageRecord`, design for quotas, integrate Stripe later.
- **Next.js full-stack**, single repo, bias hard to managed services.
- **Solo dev + Claude Code, ASAP.** First sendable CredibleAssist pitch at **M3**.
- Full architecture/roadmap plan: `~/.claude/plans/imperative-wiggling-key.md` (the canonical long-form plan; this file is the working summary).

### Tenant isolation (three layers)
1. Every tenant table has `org_id` with composite indexes.
2. All data access goes through `db.forOrg(orgId)` in [src/db/scoped.ts](src/db/scoped.ts) — raw client outside that file is a lint error. `systemDb()` in [src/db/system.ts](src/db/system.ts) is the escape hatch for public/cross-tenant reads.
3. Retrieval hard-codes `WHERE org_id = $1` **before** the vector `ORDER BY`. RLS is a later hardening step.

### Design tokens
Ground `#E9F1FA`/`#F2F6FC`, accent `#3D5BF5`, accent-2 `#4C6FFF`, ok `#22A06B`, bad `#E24545`, Inter font. Viewer stage is **1440×810** scaled by `min(100vw/1440, 100vh/810)`. Light + dark via `data-theme`.

## 5. Data model — 19 tables in [src/db/schema.ts](src/db/schema.ts)

All tables carry `id` (cuid), `org_id` FK (except `organizations`), `created_at/updated_at`.

- **organizations** — clerkOrgId, name, slug, logoUrl, accentColor, qaFallbackText, settings JSON
- **memberships** — clerkUserId, orgId, role `owner|admin|editor`
- **presenters** — name, title, headshotUrl, heygenAvatarId, voices JSON `{lang→{heygenVoiceId,elevenVoiceId}}`, **voiceSettings JSON** `{speed?,pitch?,volume?,elevenlabs?:{stability?,similarityBoost?,style?}}`, supportsMatting, idleVideoR2Key
- **documents** — filename, mime, r2Key, bytes, status `uploaded|parsing|chunking|embedding|indexed|failed|stored`, progressPct, chunkCount, **ragEnabled** (bool default true — false = store-only: status `stored`, evidence-only, never chunked/embedded/searchable; toggle re-ingests), **presentationId** (nullable FK → presentations, `onDelete: set null`; null = org-wide, else retrieval tier 2 scope), **extractedText** (full OCR/text-layer text, cached so ingest + deck-gen don't re-extract)
- **facts** — title, body, status
- **chunks** — sourceType `document|fact`, sourceId, seq, text, tokenCount, `embedding vector(1024)`, metadata JSON
- **metricLibraryItems** — key, label, rawValue, **format JSON** `{style:'number|percent|rating|duration|literal', …}`, sublabel
- **presentations** — name, slug, status `draft|live|archived`, version, defaultLang, defaultPresenterId, settings JSON (holds branding/suggestedQuestions/cannedQa/ending/appendix, `motive` narrative, and `generation`={status `generating|ready|failed`, sceneCount, error, at} polled by the Scene Builder's generation gate)
- **scenes** — presentationId, position, name, intent, templateId, **templateParams JSON**, title, subtitle, script, metricIds[], documentIds[], readiness, generationMeta JSON
- **sceneVersions** — sceneId, version, snapshot JSON
- **visualTemplates** — **orgId nullable (null = built-in)**, key, name, spec JSON, previewParams, status, source `builtin|generated`
- **templateProposals** — sceneId, proposedSpec, reason, model, status `pending|approved|rejected`
- **shareLinks** — presentationId, **code (unique, null=default)**, recipientName, langOverride, presenterOverrideId, status `live|draft|revoked`, passcodeHash, expiresAt, isDefault
- **viewSessions** — shareLinkId, startedAt, lastSeenAt, userAgent, ipHash, country
- **viewEvents** — sessionId, type `open|scene_enter|scene_complete|evidence_open|appendix_open|question|replay|exit`, sceneId, ts, payload
- **qaExchanges** — sessionId, question, answer, citations JSON, confidence, hitFallback, latencyMs, tokens/cost
- **renderJobs** — sceneId, lang, presenterId, status `queued|rendering|downloading|done|failed`, heygenVideoId, r2Key, durationSec, costUsd, scriptHash
- **sceneAudio** — renderJobId, captions JSON (word-level timestamps)
- **usageRecords** — kind `llm_generation|qa|embedding|ocr|render|tts|storage`, quantity, unit, costUsd, ref, recordedAt (`ocr` reserved; per-page OCR metering not yet wired)

## 7. Conventions & gotchas

- **Permissions:** bypass mode set in `.claude/settings.local.json` (gitignored) — don't stop to ask for routine file/command permission.
- **Next.js is modified** — read `node_modules/next/dist/docs/` before framework-level code. Heed deprecation notices.
- **React render-phase rule** enforced by lint: don't read/write refs during render. Use derived-state-during-render (`useState` + conditional `set` during render), not refs. Don't reassign closure vars after render (use `for`/`reduce`, not `let x; map(...x+=)`).
- **One formatter:** all metric formatting goes through `formatMetric()` in [src/viewer/format.ts](src/viewer/format.ts) — builder, viewer cards, scripts must match.
- **Actions & toasts (2026-07-08):** every server action returns `ActionResult<T>` via `safeAction()` ([src/lib/safe-action.ts](src/lib/safe-action.ts)); validation errors `throw new ActionError("msg")`, unexpected errors are logged server-side and genericized. Clients call actions ONLY through `useAction()` ([src/hooks/use-action.ts](src/hooks/use-action.ts)) — error + success toasts (sonner, `<Toaster>` in root layout) come free; raw fetches (R2 PUT, /api/*) use `runWithToast()`. No `prompt()`/`confirm()`/`alert()` — use shadcn `Dialog`/`AlertDialog`.
- **Admin UI = shadcn/ui:** interactive primitives (buttons, inputs, selects, menus, dialogs, switches, badges) come from `src/components/ui/`; layout wrappers keep the design-token classes (`bg-panel`, `border-line`, `shadow-card`, …). The public viewer (`src/viewer/`, `src/app/p/`) is bespoke — no shadcn there.
- **Cues are data-driven:** the 7 cue visuals render from `templateParams` JSON, not hardcoded — this is the same path M5 generated templates will use.
- **tsx compiles to CJS** (no `"type":"module"`) — no top-level await in scripts; wrap in `async function main(){}.catch()`.
- Git commits end with the `Co-Authored-By: Claude` trailer. Commit/push only when the user asks. Branch off `main` for PRs.
